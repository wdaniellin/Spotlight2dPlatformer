<h2> Features: </h2>
<ul>
  <li>Parallax, scrolling background</li>
  <li>Object oriented enemy/obstacle classes for ease of editing</li>
  <li>Custom level generator that parses pixel RGB values from a png and converts it into a playable level</li>
</ul>
